# 로도스 오퍼레이터 퀴즈

명일방주 오퍼레이터 이름을 직군별로 전부 맞히는 타이머 퀴즈입니다.
비공식 팬 콘텐츠이며 Hypergryph · Yostar의 승인을 받지 않았습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `data.js` | 오퍼레이터 목록(한국어), 종족, 별명 |
| `names.js` | 일본어·영어·중국어 이름, 직군·종족 표기 |
| `app.js` | 채점, 타이머, 언어·모드·난이도 선택, 그림자 모드, 효과음 로직, 화면 문구 번역(`T`) |
| `download_avatars.py` | (선택) 사진을 내 저장소로 내려받는 스크립트 |

## 오퍼레이터 추가하기

현재 한국 서버 기준 전체 415명이 들어 있습니다 (2026-10-14 업데이트 반영).
새 오퍼레이터는 `data.js`의 해당 직군 배열에 `["이름", 레어도, "영어 이름", "캐릭터 ID"]`을 넣으면 됩니다.

```js
"가드 GUARD": [
    ["쏜즈", 6, "Thorns", "char_293_thorns"],
    ["새 오퍼레이터", 5, "New Operator", "char_xxxx_newop"],
```

한국어 이름과 영어 이름 모두 정답으로 인정되며, 띄어쓰기·가운뎃점·하이픈은 무시됩니다.

## 별명

`data.js` 맨 아래 `ALIASES`에 적은 별명도 정답으로 인정됩니다 (예: 서카디, 보카디 → 스카디 더 커럽팅 하트).

```js
const ALIASES = {
  "스카디 더 커럽팅 하트": ["서카디", "보카디"],
  "새 오퍼레이터 이름": ["별명"],
```

키는 게임 속 이름과 정확히 같아야 합니다. 다른 오퍼레이터 이름과 겹치는 별명은 넣지 마세요.

## 언어

오른쪽 위 버튼으로 한국어, 日本語, English, 中文을 고를 수 있습니다. 고른 언어는 브라우저에 기억되고, 주소 끝에 `#ja`, `#en`, `#zh`, `#ko`를 붙이면 그 언어로 바로 열립니다. 처음 방문하면 브라우저 언어를 따라갑니다.

- 이름: 각 서버 게임 데이터의 공식 이름을 씁니다 (일본어·영어는 일본·글로벌 서버, 중국어는 중국 서버). 출연 오퍼레이터는 네 언어 모두 한국 서버 기준 415명으로 같습니다.
- 정답: 그 언어의 이름과 영어 이름이 정답입니다. 일본어는 히라가나로 쳐도 됩니다(예: すかじ). 별명(`ALIASES`)은 한국어 버전에서만 쓰입니다.
- 화면 문구는 `app.js` 위쪽 `T`에 언어별로 있습니다.
- 새 오퍼레이터를 넣을 때는 `data.js`와 함께 `names.js`의 `NAMES`에도 언어별 이름을 넣어야 합니다.

## 사진

사진은 기본적으로 공개 에셋 저장소(yuanyan3060/ArknightsGameResource)에서 바로 불러옵니다.
그 저장소가 사라질 때를 대비해 사진을 내 저장소에 같이 두고 싶다면:

1. `python download_avatars.py`를 실행하면 `avatars/` 폴더에 415장이 저장됩니다.
2. `app.js` 맨 위 `IMG_BASE`를 `"avatars/"`로 바꿉니다.
3. `avatars/` 폴더까지 같이 올립니다.

그림자 모드는 사진을 검게 칠해 실루엣만 보여줍니다.

## 난이도

입력창 줄 오른쪽 끝에서 고릅니다. 바꾸면 새 게임이 시작되고, 고른 난이도는 브라우저에 기억됩니다.

- 노말: 칸 위쪽에 성급 색 띠가 있고, 묶음 안에서 성급 높은 순으로 정렬됩니다.
- 하드: 맞히기 전까지 색 띠가 없고, 묶음(직군·종족) 안에서 순서가 매번 무작위로 섞입니다. "다시"를 누를 때마다 새로 섞입니다.

## 모드

모드 버튼은 두 줄이에요.

- 첫 줄: `직군 전체`와 직군 8개(뱅가드, 가드 …). 직군 버튼은 `data.js`의 직군 이름으로 자동 생성됩니다.
- 둘째 줄: `종족 전체`. 오퍼레이터 전체를 종족별로 묶어서 보여줍니다. 종족은 `data.js` 아래쪽 `RACE`에 있고, 묶음 순서는 `RACE_ORDER`를 따릅니다.

모드를 바꾸면 새 게임이 시작되고, 마지막으로 고른 모드는 브라우저에 기억됩니다.
모드 목록은 `app.js`의 `MODES` 배열에서 고칠 수 있습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/(root)`로 설정합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열립니다.

로컬에서 확인할 때는 `index.html`을 브라우저로 바로 열면 됩니다.
