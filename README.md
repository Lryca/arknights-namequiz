# 로도스 오퍼레이터 퀴즈

명일방주 오퍼레이터 이름을 직군별로 전부 맞히는 타이머 퀴즈입니다.
비공식 팬 콘텐츠이며 Hypergryph · Yostar의 승인을 받지 않았습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `data.js` | 오퍼레이터 목록(한국어), 종족, 별명 |
| `names.js` | 일본어·영어·중국어 이름, 직군·종족 표기 |
| `app.js` | 채점, 타이머, 언어·모드·난이도 선택, 그림자 모드, 효과음 로직, 화면 문구 번역(`T`) |
| `download_avatars.py` | 사진을 내 저장소로 내려받는 스크립트 |
